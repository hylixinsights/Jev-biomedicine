# Contributing

Use English. This version accepts documentation, declarative JSON/YAML, CSV, static examples and the preserved source workbook. Execution infrastructure belongs in a separately scoped future task.

Start with the [maintenance procedure](skills/biomedical-decision-layer/references/catalogue-maintenance.md). Preserve IDs and original option labels. Propose scientific changes in the [revision register](skills/biomedical-decision-layer/references/catalogue-revisions.md), explain the affected decision boundary, and seek domain review. Keep editorial definitions explicitly provisional until that review is recorded.

For examples, supply synthetic or appropriately authorized public material with clear provenance. Do not commit identifiable participant data, credentials, or unattributed copied papers. Keep source excerpts distinct from instructions. Record source URL, access date and revision when available. Do not claim biomedical validation from interface documentation or synthetic tests.

Review JSON/YAML syntax, exact workbook-to-JSON mapping, domain pages and local links. Test a copied skill folder with no access to repository-root files. A useful preparation test starts with a short scientific question and a few raw columns, then checks selection, mapping, missingness and a handoff without inference. Record evidence and limits in VERIFICATION.md.

No license has been selected by the repository owner. Do not assign one or invent a DOI, authorship statement, institutional endorsement or model performance result.
